# Rishabh Srivastava — Portfolio

Personal site for [Rishabh Srivastava](https://github.com/rishabh71206).

**Live:** https://rishabh71206.github.io/rishabh-srivastava-portfolio/

## Stack

Hand-written, dependency-free and fast to load:

- **HTML5** — semantic landmarks, ARIA where it matters, Open Graph + Twitter cards, JSON-LD `Person` schema
- **CSS** — custom properties, `clamp()` fluid type, grid, `color-mix()`, light/dark themes, `prefers-reduced-motion`
- **JavaScript (ES2022)** — vanilla, no build step: scroll reveals, animated counters, progress bar, theme toggle, mobile nav, magnetic buttons, 3D tilt, custom cursor
- **GitHub Pages** — deployed straight from `main`

## Featured project

[Smart AI Resume Analyzer](https://github.com/rishabh71206/smart-ai-resume-analyzer) — Python 3.12, Streamlit, and Gemini 2.5 Flash, with a deterministic offline engine and 36 tests.

Live demo: [Streamlit app](https://smart-ai-resume-analyzer-nfdlpabrwsiiuvghfphuzv.streamlit.app/)

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
python -m http.server 5173
```

Then visit `http://127.0.0.1:5173/`

## Deploy

Every push to `main` is published by GitHub Pages (branch deploy, repository root).
